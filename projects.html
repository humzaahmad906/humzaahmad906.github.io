PackageX · CV · OCR

On-prem document pipeline for conveyor logistics

Real-time entity extraction from logistic documents on a moving conveyor. Line-scan camera tracking with optimal-frame selection per document, a custom-trained OCR engine, LayoutLMv3 classification, and per-document-type entity models. 94% F1 in-house vs 65% for GPT-4o.

PackageX · VLMs · Quantization

Compact VLM track for edge deployment

Qwen3.5-VL 0.8B/2B fine-tuned on a synthetic logistics corpus generated from 80+ carrier-label templates with print-simulation augmentation. SFT → DPO → QAT (PyTorch + TorchAO) with per-layer sensitivity maps. Ships 4-bit on-device via MLX Swift (iOS) and Linux/CUDA, matching server accuracy.

PackageX · SDK · Packaging

Cross-platform on-prem SDK

Packaged the full document-processing pipeline as a deployable on-prem SDK — Python pip wheel for Linux/CUDA, and a Swift package for iOS/MLX. Lets internal teams drop the model stack into new product surfaces without re-deriving training/inference plumbing.

RevolveAI · NLP · RAG

Hellofact — web crawling & QA

Downloads PDFs from the web, OCRs them, categorizes by content/metadata, indexes into MongoDB + Pinecone with embeddings, and answers user questions from the most-similar context sub-documents. Python, AsyncIO, FastAPI, HuggingFace, Selenium, Zen-scrape, OpenAI.

RevolveAI · CV · Multi-camera

Multi-camera person identification

Tracks a person across cameras using face and body embeddings. On first appearance, registers identity in Redis + MySQL; on re-appearance, matches via cosine similarity. Embeddings reload from MySQL into Redis on server restart. OpenCV, TensorFlow.

Cipher Savvy · LLMs · Summarization

Tweet generator & doc search for news

Pulls news articles, transforms with GPT-3, fine-tunes Llama 2 and FlanT5 for concise tweet generation. Built around LlamaIndex, HuggingFace, and PyTorch; evaluated with ROUGE.
